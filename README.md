# 看山牌桌 / Kanshan Table

由刘看山担任 DM 的多人文字共创 Web 游戏。玩家通过房间码和临时昵称入席，轮流用不超过 140 字共同完成一篇回答或故事。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。第二位玩家可使用另一个浏览器或无痕窗口加入同一房间。

需要让同一局域网内的设备加入时运行：

```bash
npm run dev:lan
```

DeepSeek Key 优先从环境变量 `DEEPSEEK_API_KEY` 读取；当前 macOS 开发机也可从钥匙串服务 `kanshan-table.deepseek` 读取。没有配置模型时，游戏会自动使用本地评分降级，不阻断回合。

## 主要能力

- 2～6 人临时房间与昵称身份
- 准备、随机执笔、抢笔、倒计时和 140 字限制
- 问题模式与故事模式
- DeepSeek 结构化言值评分与本地降级
- 知乎热榜取题与离线候选题
- 两种模式各四张创作卡牌
- 收笔投票、共同作品和玩家结算
